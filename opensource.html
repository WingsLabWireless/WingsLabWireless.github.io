WINGS Lab Open Source

This page collects open-source projects from the WINGS Lab, including hardware designs, software stacks, and reusable experimental assets. Each project below includes a short overview and a link to its dedicated page.

Before proceeding, please review the License Statement.

Projects

BenchLink

Experiment orchestration Edge systems Reproducibility

Overview: BenchLink is a reusable workflow layer for connecting experiments to real hardware and test sites, supporting repeatable runs, configuration management, and structured data capture.

  • Unified experiment configuration and run logging.
  • Pluggable backends for different radios, UAVs, and edge devices.
  • Designed to support “sim-to-real” and field-test repeatability.
Project page →

WINGS-4039

Open UAV platform Modular payload Deep programmability

Overview: WINGS-4039 is an open, modular UAV platform that targets research-grade experimentation across communications, networking, and autonomy. The platform emphasizes payload capacity, integration flexibility, and reproducible field testing workflows.

  • Modular avionics + payload bays for SDR / compute / sensing modules.
  • Interfaces for experiment control, telemetry, and synchronized logging.
  • Designed as part of a larger WINGS open UAV ecosystem.
Project page (coming soon) →

OSWireless

Intent-driven networking Software-defined wireless Automated optimization

Overview: OSWireless is a control plane for optimizing software-defined wireless networks, converting high-level control intents into distributed control programs that run on programmable network nodes.

  • High-level intent specification APIs that hide mathematical and algorithmic detail.
  • Automated decomposition of centralized control problems across layers and nodes.
  • Generated optimization algorithms deployable on SDR testbeds.
Project page →

StormWave

Overview: StormWave is an open-source, portable software-defined Radio Frequency (RF) interference generation and monitoring platform designed for realistic field-based evaluation of the resilience of wireless communication systems.
