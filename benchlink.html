BenchLink

Experiment orchestration Reproducibility Edge & UAV systems

Overview

BenchLink is an open-source experiment orchestration and integration framework that bridges algorithm development, real hardware, and field deployments. It provides a structured layer for configuring experiments, managing execution, and collecting synchronized results across heterogeneous platforms.

BenchLink emphasizes portability and repeatability, enabling researchers to move seamlessly from lab-based testing to outdoor and field experiments.

Hardware

  • UAV platforms with onboard compute and SDR payloads
  • Ground-based radios, spectrum sensors, and edge servers
  • Heterogeneous compute nodes (x86, ARM, SoC-based systems)

Hardware dependencies are abstracted through adapters so that experiment definitions remain portable across platforms.

Software

  • Declarative experiment configuration and parameter management
  • Pluggable backends for radios, UAV controllers, and edge services
  • Structured logging and artifact collection for post-analysis

BenchLink integrates with existing research code and control software rather than imposing a monolithic framework.

Testing

  • Local and lab-based functional testing
  • Hardware-in-the-loop experiments
  • Outdoor and field deployments with repeatable configurations

Consistent experiment descriptions and logging enable fair comparison across runs, platforms, and environments.
